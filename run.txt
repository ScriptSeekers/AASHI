2. HOW TO RUN THE BACKEND SERVER
================================================================================
Requirements: Node.js 18+ (Node 20+ recommended)

Step 1: Open a terminal and navigate to the backend folder:
   cd backend

Step 2: Install dependencies (if not already installed):
   npm install

Step 3: Generate the Prisma client:
   npx prisma generate

Step 4: Start the backend in development mode:
   npm run dev

   Backend will be running at:
   - REST API:   http://localhost:3001/api
   - Socket.IO:  ws://localhost:3001
   - Database:   backend/prisma/dev.db (SQLite)

Additional Backend Commands:
   - Run Vitest Test Suite (20 tests):   npm test
   - Inspect Database with GUI Studio:   npm run db:studio
   - Re-seed Accounts (Arpit & Shree):   npm run db:seed
   - Compile Production TypeScript:      npm run build
   - Run Production Server:              npm start

================================================================================
3. HOW TO RUN THE FRONTEND CLIENT
================================================================================
Step 1: Open a second terminal window and navigate to the frontend folder:
   cd frontend

Step 2: Install dependencies (if not already installed):
   npm install

Step 3: Start the Vite development server:
   npm run dev

   Frontend will be running at:
   - Web App URL: http://localhost:5173

   (Vite automatically proxies /api and /socket.io requests to port 3001)

Additional Frontend Commands:
   - Type-check & Production Build:      npm run build
   - Preview Production Build:           npm run preview
