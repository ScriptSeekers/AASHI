3. HOW TO DEPLOY FRONTEND ON VERCEL
================================================================================
Option A: Deploy via Vercel CLI:
  1. Open terminal and go to frontend:
     cd frontend
  2. Run:
     npx vercel
  3. When asked:
     - Root Directory: `.` (or select `frontend` if importing the whole repo)
     - Framework: Vite
     - Build Command: `npm run build`
     - Output Directory: `dist`
  4. Environment Variables on Vercel:
     Add: `VITE_BACKEND_URL` = `https://aashi-8uri.onrender.com`

Option B: Deploy via Vercel Dashboard (GitHub import):
  1. Push repository to GitHub.
  2. In Vercel Dashboard, click "Add New Project" -> Import Git repository.
  3. Set Root Directory to: `frontend`
  4. Set Environment Variable:
     - Key: `VITE_BACKEND_URL`
     - Value: `https://aashi-8uri.onrender.com`
  5. Click Deploy.

================================================================================
4. IMPORTANT NOTE FOR RENDER BACKEND
================================================================================
In Render Dashboard:
  - Build Command:
    npm install && npx prisma generate && npx prisma db push --skip-generate && npm run build
  - Start Command:
    npm start
    (which executes: npx prisma db push --skip-generate && node dist/index.js)

This ensures the SQLite tables and Arpit & Shree accounts are initialized in Render's storage.

================================================================================
5. LOCAL DEVELOPMENT
================================================================================
To run the frontend locally while connecting directly to your live Render backend:
  cd frontend
  npm install
  npm run dev

Open `http://localhost:5173` to interact with your live Render backend!
